- Automated Android build

## Workflow Steps

```text
Code Push
   ↓
GitHub Actions Start
   ↓
Checkout Source
   ↓
Setup Java + Android SDK
   ↓
Install Dependencies
   ↓
Run Tests
   ↓
Gradle Build
   ↓
Generate APK/AAB
   ↓
Upload Artifact
```
